# 共享打印 · 桌面助手（WebPrint Desktop）v2.0

不依赖浏览器的**独立桌面应用**，与服务端分开安装：任何一台电脑装上它，填好服务端地址就能远程打印，操作和 App 一致。

v2.0 界面引擎全新重做：网页级渲染（系统 WebView）+ 渐变品牌顶栏、启动动画、卡片式布局，告别老式控件界面。

## 获取安装包

1. 打开仓库 Releases 页（<https://github.com/tsy-yyds/webprint-server/releases>），下载 **`共享打印桌面助手.exe`**（约 48 MB，免 Python 环境）；
2. 也可以下载本目录源码（`app.py` + `ui.html`），用 `build.bat` 自己打包（需先 `pip install pywebview pyinstaller`）。

## 使用方法

1. 双击 **`共享打印桌面助手.exe`** 运行（带启动动画），在顶部输入服务器地址：
   - 局域网：`http://电脑IP:8000`（例如 `http://192.168.3.17:8000`）
   - 外网：你的公网地址（Tailscale / cpolar）
   - 填过会自动记住，下次打开自动连接
2. 点「连接」，自动获取服务器上的打印机列表；
3. 点「+ 添加文件」选择本机要打印的文件（PDF / 图片 / TXT / Word / Excel / PPT）；
4. 调好份数、方向、颜色、纸张、双面、缩放、质量 → 点「开始打印」；
5. 选「打印到 PDF（存服务器）」→ 点「转换为 PDF」，结果存在服务器的「打印输出」文件夹，可在下方「④ 服务器 PDF 输出」列表选中并下载到本机；
6. 手动双面：打印完第一面会弹出翻面提示窗口（带三步示意图），翻面放回纸盒后点「下一步，继续打印」，打印完背面；放反了可以「取消任务」。

## 与网页 / 手机 App 的关系

- 三端共用同一个打印服务，地址、配置完全一致；
- 客户端独立运行，不打开浏览器；
- 若服务器设置了访问密码（PIN），连接时输入一次，之后自动记住。
