变成手机也能用的网络打印机

打印机不需要支持网络功能，电脑也不用公网 IP。装好之后，手机和电脑在同一 WiFi 下直接打印；人在外面，用免费穿透也能远程打印。

它能做什么

一个装在打印电脑上的小服务，把打印这件事变简单。

打印到纸

上传文件、选打印机、调份数/方向/纸张/缩放，点一下开始打印，后台队列逐个输出。

手动双面

手动双面打印机友好：先打奇数面，手机弹出图文教程提示翻面放纸，点「下一步」再打背面，页码不乱。

打印到 PDF

不想费纸？把文件转成 PDF 存到电脑「打印输出」文件夹，手机或电脑随时下载。

外网也能打

人在外面想打印？免费方案二选一：cpolar（手机零安装）或 Tailscale（地址固定），详见使用说明。

三分钟用起来

只需要一台 Windows 电脑 + 一根 USB 连接打印机的线。

装一次

把工程文件夹拷到打印电脑上，双击 install.bat，等依赖装完（自动走清华镜像，国内快）。

启动服务

双击 start.bat，后台静默运行、无黑窗口，自动打开打印网页。想开机自启用 启用开机自启.bat。

手机直接打

手机连同一 WiFi，浏览器打开 http://电脑IP:8000，选文件、选打印方式，点「开始打印」。想让手机更像 App？浏览器「添加到主屏幕」，或直接用下面的安卓 App。

安卓 App「共享打印」

微信 / QQ 里收到的文件，用其他应用打开，直接选「共享打印」就能打；打完自动清理手机暂存，不占空间。

获取安装包：打开 仓库 apk/ 文件夹，下载 13 个 b64_part*.txt 分块文件和 还原APK.bat，放同一文件夹后双击 还原APK.bat，几秒后生成 共享打印.apk，发到手机安装即可。

分块是为了在 GitHub 上存放安装包文件（平台不允许直接上传二进制），还原脚本一键合并，不需要任何操作技巧。

常见问题

手机打不开网页？

确认手机和电脑连的是同一个 WiFi；双击 开放防火墙.bat（右键以管理员身份运行）放行端口；电脑 IP 变了就在 cmd 里输 ipconfig 看最新 IPv4 地址。

网页打开了但没看到打印机？

检查打印机 USB 是否插好、驱动是否正常；点打印机旁边的刷新按钮；服务启动后才插的打印机，重启一次服务（先 stop.bat 再 start.bat）。

开放到外网安全吗？

建议在 config.json 里设置访问密码（pin），之后任何人打开网页都要先输密码。详细的安全提醒见使用说明第八节。

Word / Excel / PPT 能打吗？

能，但打印电脑上需要装有 Office 或 WPS，服务会自动调用转换。没装的话先把文件转成 PDF 再传。
