核心特色

不挑打印机、不挑电脑，把打印这件小事做顺。

打印到纸

上传 PDF / 图片 / TXT / Word / Excel / PPT，选打印机、调份数方向纸张，点一下开始打印，后台队列逐个输出。

手动双面

手动双面打印机友好：先打奇数面，手机弹出图文教程提示翻面放纸，点「下一步」再打背面，页码不乱，支持取消重打。

打印到 PDF

不想费纸？把文件转成 PDF 存到电脑「打印输出」文件夹，手机或电脑随时下载，多文件自动合并成一册。

外网也能打

人在外面想打印？免费方案二选一：cpolar（手机零安装）或 Tailscale（地址固定），远程照打不误。

电脑客户端

不依赖浏览器，独立桌面应用：选文件、选打印机、调打印方式，窗口里完成全部打印操作。

访问密码

开放到外网时可在配置里设置 PIN 密码，任何人打开都要先输密码，防止别人乱打。

三步装好

以「服务端 + 手机」为例，整个过程约三分钟。

装服务端

把 共享打印服务.exe 放到打印电脑上（建议放桌面或固定文件夹），双击运行。首次运行会自动生成配置文件，并打开打印网页。

手机连上

手机连同一 WiFi，打开 App（或浏览器）输入电脑的局域网地址，例如 http://192.168.3.17:8000。地址在服务端网页底部能看到。

选文件打印

选文件、选打印机、调打印方式，点「开始打印」。手动双面时按提示翻面继续；人在外面就填外网地址（见使用说明）。

常见问题

手机打不开网页 / 连不上服务器？

确认手机和电脑连的是同一个 WiFi；双击服务端目录里的「开放防火墙.bat」（右键以管理员身份运行）放行端口；电脑 IP 变了就在 cmd 里输 ipconfig 看最新 IPv4 地址。

网页打开了但没看到打印机？

检查打印机 USB 是否插好、驱动是否正常；点打印机旁边的刷新按钮；服务启动后才插的打印机，重启一次服务。

开放到外网安全吗？

建议在 exe 旁的 config.json 里设置访问密码（pin），之后任何人打开网页都要先输密码。详细安全提醒见使用说明第八节。

Word / Excel / PPT 能打吗？

能，但打印电脑上需要装有 Office 或 WPS，服务会自动调用转换。没装的话先把文件转成 PDF 再传。
